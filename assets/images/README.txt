IMAGES FOLDER
Put photos, book covers, mockups and portfolio images here.
Suggested names:
  hero-book.png       (hero artwork)
  cover-01.jpg ...    (portfolio items)
  og-image.jpg        (social sharing image, about 1200x630px)
Tips:
- Keep files small (under about 300 KB each) so the site loads fast.
- Use JPG for photos, PNG for graphics with transparency, WebP if you know how.
- Always write meaningful alt text in index.html: describe the image.
