LOGOS FOLDER
Put your logo files here. Suggested names:
  davenport-books-logo.svg   (or .png)
  davenport-labs-logo.svg    (or .png)
SVG is best because it stays sharp at any size. If you use PNG, export it at
2x the size it will be shown, with a transparent background.
See the "logo placeholder" comments in index.html (header and About section)
for exactly what to change.
